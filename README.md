   # 🌐 Ref Doc Page — Advanced CSS Documentation Website

Welcome to **Ref Doc Page**, a modern and responsive documentation-style landing page built entirely using **HTML** and **advanced CSS** — with a small touch of **JavaScript** to introduce interactive features.

This project is part of my ongoing journey as a front-end developer, focusing on **layout design**, **color accessibility**, **navigation systems**, and **modern responsive styling**.

---

## ✨ Highlights & Features

- 🎨 **Beautiful, accessible color blending** — designed for readability, even for color-blind users.  
- 📱 **Fully responsive layout** — adapts smoothly across all screen sizes.  
- 🍔 **Interactive hamburger menu** for easy mobile navigation.  
- 🌗 **Dark & Light Mode** toggle — my first feature using a bit of JavaScript logic!  
- 🔗 **Functional internal links** for seamless navigation.  
- ⚡ **Fast-loading structure** — optimized with clean, semantic HTML.  
- 🧩 **Well-structured codebase** — consistent indentation, organized styles, and clear naming.
